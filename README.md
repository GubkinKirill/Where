# Учёт техники и комплектующих

Веб-приложение для учёта компьютерной техники, комплектующих и одноплатных компьютеров
на небольшом предприятии. Разворачивается внутри локальной сети, в интернет не выставляется.

Масштаб: около 20 компьютеров, 150–300 единиц учёта, до 10 одновременных пользователей.
Приоритет — простота сопровождения, а не масштабируемость.

## Главная идея

**Компьютер и комплектующее — одна и та же сущность.** Системный блок, монитор, планка
памяти, SSD, блок питания, Raspberry Pi — всё это `Item` (единица учёта). Отличаются только
типом и набором атрибутов.

Разница между «компьютером» и «комплектующим» выражается не таблицей, а размещением:
планка памяти внутри системного блока — это комплектующее в его составе; та же планка
на полке шкафа — позиция склада. При перемещении запись не дублируется, меняется размещение.

Размещений шесть видов: внутри другой единицы, на складе, у сотрудника, в кабинете,
передано за пределы отдела, списано.

**Текущее размещение нельзя отредактировать формой.** Оно вычисляется из журнала
перемещений: любое изменение — это новая запись в журнале, единственная точка входа —
сервисная функция `move_item()`. Поле размещения в `Item` — денормализованный кэш,
который обновляет только она.

## Стек

Python 3.11+ · FastAPI · SQLite + SQLAlchemy 2.x · Alembic · Jinja2 + HTMX ·
Pydantic v2 · qrcode + Pillow · pytest.

Фронтенд-сборщиков нет: серверный рендеринг плюс HTMX, один статический CSS-файл,
никаких npm-зависимостей. Приложение запускается одной командой без предварительной сборки.

| # | Этап | Статус |

## Прототип интерфейса

Статические макеты в `prototype/` — карточка единицы, список с фильтрами, форма выдачи.
Бэкенда не требуют:

```bash
cd prototype
python3 -m http.server 8077 --bind 127.0.0.1
```

Затем открыть <http://127.0.0.1:8077/item.html>.

## Ограничения

- Сканирование QR камерой браузера требует HTTPS либо `localhost`. В локальной сети по HTTP
  камера может быть недоступна — в режиме сверки всегда доступен ручной ввод номера.
- ФИО сотрудников — персональные данные: не логируются и не выводятся в URL.
