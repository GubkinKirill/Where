Раздел для того, кто разворачивает систему и ведёт справочники.

Кому нужна учётная запись

Только тем, кто ведёт учёт: обычно это один-два человека из технического отдела. Рядовым сотрудникам записи не заводятся — они пользуются страницей «Моя техника» по табельному номеру.

РольПрава
adminвсё: справочники, шаблоны комплектности, удаление записей
editorперемещения и карточки единиц, справочники только на просмотр
viewerпросмотр списков, карточек и отчётов

Создать запись или сменить пароль — из командной строки на сервере:

python -m scripts.create_admin ivanov --role admin --full-name "Иванов И. И."

Пароль спросят интерактивно, минимум восемь символов. Той же командой меняется пароль существующей записи.

Если загружали демо-данные, в системе есть записи admin, kgubkin и viewer с общеизвестными паролями. Перед началом настоящей работы заведите свою и удалите демонстрационные.

Справочники

СправочникЗачем
Типы единицзадают префикс номера (PC, ANT) и признак контейнера
Сотрудникикому выдают технику, с табельными номерами
Отделыкод и название, например 235 — Технический отдел
Кабинетыномер, этаж, описание
Места храненияшкафы, полки, ячейки — вложенные друг в друга

Типы единиц

Код типа становится префиксом инвентарного номера, и менять его после того, как номера выданы, не стоит: наклейки на корпусах не переклеятся. Признак «может содержать вложенные единицы» ставится системным блокам, одноплатным компьютерам и комплектам поставки.

В поле «Подсказываемые атрибуты» перечисляются ключи дополнительных полей, по одному в строке: назначение, образ ОС, MAC, IP. Форма будет их подсказывать, но не ограничивать.

Места хранения

Строятся иерархией: «Шкаф 1» → «Полка 2» → «Ячейка A». В списках путь показывается целиком, поэтому названия можно делать короткими. Код (SHELF-02) пригодится позже, когда появятся наклейки с кодами.

Удаление записей справочника

Если на запись кто-то ссылается — например, на кабинет назначены сотрудники, — система откажет в удалении. Это защита истории: удаление разорвало бы связи в журнале. Для вышедшего из употребления снимайте флажок «Используется» вместо удаления.

Установка и запуск

python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

cp .env.example .env          # поправить BASE_URL и SECRET_KEY
alembic upgrade head          # создать структуру БД
python -m scripts.seed_demo   # необязательно: демо-данные

uvicorn app.main:app --host 0.0.0.0 --port 8000

Ключ --host 0.0.0.0 нужен, чтобы приложение было видно с других машин и с телефонов в той же сети. В .env пропишите BASE_URL — адрес, по которому система доступна.

Обновление версии

git pull
pip install -r requirements.txt
alembic upgrade head

Резервное копирование

Все данные лежат в одном файле SQLite — по умолчанию data/inventory.db. Копировать его нужно средствами самой SQLite, чтобы не поймать копию на середине записи: 

sqlite3 data/inventory.db ".backup 'backups/inventory-$(date +%F).db'"

Проверяйте, что копия открывается и в ней есть данные. Резервная копия, которую ни разу не восстанавливали, — это ещё не резервная копия.

Чего система пока не делает

  • QR-кодов и печати наклеек нет — отложено;
  • количественного учёта расходников (мыши, патч-корды) нет: всё считается поштучно;
  • фотографий, режима сверки и выгрузки в Excel нет;
  • уведомлений по почте нет и не планируется: почтового сервера у приложения нет.
